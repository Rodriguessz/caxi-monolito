# Caxi — monólito

ERP mobile-first para feirantes e vendedores permissionários.

Este repositório é construído em etapas, cada uma entregue por Pull Request:

1. API NestJS mínima + Docker Compose (API + PostgreSQL)
2. Testes básicos
3. Pipeline de CI no GitHub Actions
4. Proteção da `main` e regras de PR
5. Documento explicando o conjunto
